Programming for AI: Assignment 3
This notebook uses NumPy, Pandas and Matplotlib on real measurement data.
It covers code tracing, debugging, a sensor-cube analysis, weather-station
cleaning, student-performance statistics, a nine-panel dashboard, and
surface plots with an animation.
How to run
1. Install Python 3 with numpy, pandas, matplotlib and pillow.
2. Keep the notebook next to the `data/` folder (the four data files).
3. Open `Assignment3_Programming_for_AI.ipynb` in Jupyter.
4. Choose Kernel > Restart and Run All.
Outputs
The run creates `dashboard.png`, `dashboard.pdf`, `wave.gif`,
`q7a.png` and `q7b.png` in the notebook folder.
The Difficult part:
Matplotlib was the hardest part. It has many similar commands, such as `plt.` versus `ax.`,
and each plot type takes different arguments. They are hard to memorise,
so I relied on the documentation and tested each panelone at a time.
